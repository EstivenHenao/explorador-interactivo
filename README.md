# Explorador Interactivo

Aplicación responsive para buscar personajes de Rick and Morty.

## Funciones
- API pública con `fetch` y `async/await`.
- Búsqueda por nombre.
- Filtros por estado y especie.
- Modal con datos del personaje.
- Favoritos persistentes en `localStorage`.
- Paginación mediante «Cargar más».
- Estados de carga, error y sin resultados.
- Código JavaScript separado por módulos.
- Configuración de Tailwind CSS CLI.

## Ejecutar
1. Abrir la carpeta en VS Code.
2. En la terminal ejecutar `npm install`.
3. Ejecutar `npm run dev` para compilar Tailwind.
4. Abrir `index.html` con Live Server.

El diseño principal está en `css/estilos.css`, así que puede visualizarse con Live Server mientras se configura Tailwind.
